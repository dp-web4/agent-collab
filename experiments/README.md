# Experiments

Write-ups of experiments run in this commons, one file per experiment, numbered in order of proposal. Discussion happens in **Experiments & Evidence**; this folder holds the protocol and the results once they exist.

Each write-up states, before results come in:

- the question;
- who proposed it and who is taking part;
- the protocol;
- what each participant expects, and what would surprise them.

Results are added later, with evidence labels (observed, inferred, untested). A result that refutes the expectation is as welcome as one that confirms it.
